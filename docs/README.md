# cert-me 개발 설계 문서

홈랩용 PKI 발급·관리·배포 서비스. 웹 대시보드와 curl 다운로드를 제공하며 Docker 단일 인스턴스를 기본으로 한다.

2026-09-09 기준 기획 정책이다. 구현 완료를 뜻하지 않는다. 정책은 아래 담당 문서에서 정의하고, 검증 문서는 그 정책을 확인하는 기준으로 사용한다. 문서 간 우선순위로 충돌을 숨기지 않고 정책 변경 시 관련 검증 항목도 함께 수정한다.

| --- | --- |
| [제품·운영·보안](./architecture.md) | 기술 스택, 관리자·세션, HTTPS, 저장 암호화, CLI 복구, 감사, 장기 권한 |
| [인증서 수명과 배포](./certificate-lifecycle.md) | 발급 프로필, 갱신, 일회성 수령, CA 전환, CRL 발행 |

기존 `mvp-decisions.md`의 결정은 담당 문서에 병합했다. MVP의 잔여 미결정 표시는 제거했으며 교차 서명·ACME·CA별 관리자·태그 ACL·OCSP·metrics의 상세 설계는 해당 장기 기능 착수 시 수행한다. 데이터 모델·API·DB 마이그레이션 설계는 별도 문서에 정의했다. 초기 OpenAPI·SQL과 의존성은 작성했으며 실제 검증 범위는 버전·실행 아티팩트 문서를 따른다. 운영 마이그레이션 실행기와 애플리케이션은 다음 구현 범위다.
